# 墨记 · 通用 DPT 文档与笔记助手

支持 Sony DPT-RP1 的文件传输、按文件夹增量同步批注、手写识别、结合原文解答、笔记知识库和解读历史。内容可以是工作资料、技术文档、书籍或任何其他 PDF，不预设语言和主题。

## 选择同步范围

1. 在“连接与设置”填写 DPT 地址，确认已配对且设备唤醒。
2. 打开“设备文件”，点击“刷新设备目录”。此步骤只更新目录与文件元数据，不下载正文或批注。
3. 在“同步文件夹”勾选目录；也可以输入 `Document/工作资料` 这类路径。
4. 点击“保存同步范围”，然后“同步并解读”。之后后台会按设置的间隔检查。

范围包含子文件夹。例如 `Document/工作资料` 包含 `Document/工作资料/项目/a.pdf`，但不包含 `Document/工作资料备份/a.pdf`。多个目录可以同时选择；重叠选择会合并。选择 `Document` 明确表示同步整个设备的 PDF。

新文档只要放入所选目录，下次同步会自动加入，不需要逐份开启跟踪。名称含 Note 的文档也按相同规则处理。范围外的文件不会被下载、提取笔记、自动解读，或作为其他问题的关联笔记发送给模型；单份拉取接口也不能绕过范围。刷新目录会读取设备全量元数据，以便显示文件夹选择器。

清空选择会暂停文档与笔记同步，不删除已有知识库、PDF 副本、笔迹或解答。知识库仍可查看范围外的历史记录，并显示归档提示。若想继续解读，应将其所属目录重新加入范围。

上传 PDF 的目标目录必须在同步范围内。切换同步范围后，若旧上传目录已不在范围内，默认改为第一个所选目录；也可在设置中指定其子目录。同名上传另存，保留已有批注，并通过回读校验。

## 在网页整理文件

在“设备文件”的文件列表工具栏中可以新建文件夹；勾选 PDF 后，列表上方会出现批量操作条，可将所选文件移动到目标目录。路径从 `Document/` 开始；移动目标不存在时会创建。

例如整理同一主题的资料：

1. 新建 `Document/项目资料`。
2. 取消“只看同步范围内”，搜索并勾选需要整理的 PDF。可以按原目录搜索，然后用表头复选框全选当前列表，继续搜索和追加选择。
3. 在批量操作条中将“移动到”填写为 `Document/项目资料`，点击“移动所选文件”。如需分层，也可分别移动到这个目录的不同子目录。
4. 移动完成后，在“同步文件夹”中勾选新目录并保存。整理文件本身不会自动扩大同步范围。

移动使用设备原生的父目录更新接口，保留设备文档标识。知识库按该标识识别移动或重命名，保持已有文档、笔记与解答的关联；不把同一文档移动后的批注重复归档。若用 DPT 自身整理，下次刷新目录也会跟踪该标识。

每次移动先下载当前 PDF 到数据目录的 `move-backups`，再执行移动并回读比较 SHA-256。成功时保留移动前副本；若内容变化，保留前后两份副本并报告，供用户核对，不擅自回滚或覆盖。批量移动需传输文件进行校验，速度与 PDF 大小有关。

目标存在同名文件、批次中有同名文档或目标路径属于另一个历史归档时，会在移动前拒绝冲突。网络中断等情况可能使部分文件已移动，因此会重新读取目录并按稳定标识校准；页面显示已校验的数量和失败原因。文件操作需设备唤醒，但不需要模型，也不会将范围外文档的备份提取成笔记或发送给模型。

备份会占用额外存储，并包含用户文档；完整备份应用数据时应保留 `move-backups`。当前没有自动清理策略。

## 旧版本升级

旧版本保存的笔记、解答、PDF、配对信息、模型地址与密钥都会保留。新安装从空文档库开始。

首次升级到文件夹同步时，旧的逐文件跟踪列表会暂停，等待用户明确选择目录。请部署后到“设备文件”重新选择同步文件夹并保存。

新安装从空文档库开始，默认不复制任何配对凭据。可在网页配对，或通过部署命令的 --include-pairing 显式迁移本机凭据；后续内容来自所选设备目录。

## 笔记与模型

笔记工作台默认按“PDF → 笔记 → 正文”分层组织。顶部工具栏放搜索、带计数的筛选页签、“按 PDF / 按时间”切换和导出；左侧导航把 PDF 与笔记合成一棵可折叠的树，展开的 PDF 下缩进列出它的笔记；右侧正文区保留单条笔记的原始笔迹（可点击放大）、转写、解答、校正与历史，正文区足够宽时笔迹与解答左右并排对照，较窄时上下排列。手机宽度下先显示导航，点开笔记后进入正文，用“返回列表”回到导航。在笔记视图中可用 j / k 切换笔记，用 / 聚焦搜索。存在未读回复的文档优先排列，同组按最新活动排序；读取设备目录或重复同步不会把旧文档当作新消息置顶。点击“按时间”可切回跨文档的笔记列表，浏览器会保存这一偏好。

选择 PDF 会加载该文档的笔记，选择一条笔记才展示对应正文。当前打开的笔记及其解答会标为已读，其他笔记的未读状态保留；页面隐藏或切换到其他视图时停止自动已读。操作同时到达的新解答不会被旧回执清除。搜索可匹配 PDF 名称、笔记文字和解答，导航中的 PDF 行保留对应 PDF 的完整有效笔记数与未读数。

无意义或不想处理的笔记可以直接“忽略”，不必先确认识别结果。忽略后不再出现在默认列表、待确认、待解读、未读计数、笔记回顾或相关笔记上下文中，也不再自动调用模型；原始 PDF、笔迹、已有解答和历史仍保留。打开顶部“已忽略”筛选即可查看与恢复，JSON/Markdown 导出也会保留忽略标记。

重复同步以及同一批注后续被修改，都不会自动取消忽略；需要继续处理时手动恢复。恢复后保留原处理状态，旧回复不会重新变为未读。忽略过程中已发出的模型请求无法撤回，但返回的结果会被丢弃，避免再次弹出待确认或新回复。忽略只影响应用内的处理，不修改 DPT 上的批注。

服务提取 PDF 中的 Ink、Highlight、Text 等批注，合并相邻标记，保留笔迹截图、附近正文、文档与页码。被压平成页面图像的手写内容不能作为增量批注提取。

批注按标识和内容指纹去重：重复同步不重复建笔记或解读；修改笔迹后重新识别，先前的解答和 PDF 版本继续保留。识别不够确定时进入“待确认”，支持人工校正文字后解读。

模型根据实际文档主题解答。只有标记时解释所标记内容，缺少上下文则明确指出。新解读显示为未读回复，网页每隔几秒更新。浏览器关闭后，服务器仍继续同步与解读，但设备需处于可连接状态；服务不能远程唤醒休眠的 DPT。

如果批注是在作答（例如圈选选项、打勾或写下解题结果），同步解读时会主动核对当前批注对应的题目，不必再手写“请批改”。适用于真题、练习册和普通文档中的题目，文件名只作线索，不依赖特定考试或学科。

模型同时看到当前批注截图和该批注所在的完整页，扫描 PDF 没有可提取文字时也可读取题干与选项。完整页按 PDF 版本缓存在数据目录的 `page-context` 中。只分析当前批注对应的题目；不会自动批改同页所有题目或全文。

识别出错题时，解读会列出题号、你的作答、建议答案、错因、正确解法、必要的选项辨析与具体知识点，并随笔记保留解读历史，支持 JSON 和 Markdown 导出。做对时简要说明理由。文中明确给出答案时标注“依据文中答案（模型核对）”并引用；其他情况标注“模型推导的参考解答”。这些属于模型判断，文件名为真题不代表获得了官方答案。

最终作答不明确时先核对转写。缺少跨页题干、必要选项、听力音频或文字稿、答案依据，或解题置信度不足时显示“暂不能判定”与需补充的信息，不强行认定答错。当前不会自动检索其他页或独立的答案册，也不会处理听力音频。

在设置中填写 API Base URL、支持图片的模型名称与可选 API Key。Base URL 留空表示未配置，不会自动选择提供商；密钥输入框留空则保留已有密钥。接口测试只检查文字与 JSON 调用，视觉识别需用真实笔迹验证。

程序负责同步、校时、批注提取、去重、归档、检索和统计。模型负责手写识别、意图理解、作答核对和问题解答。只向模型发送所选范围内的笔迹截图、该批注所在完整页的图像与文字和少量相关笔记，不发送配对密钥或整个 PDF。使用者应填写自己信任的模型服务。

笔记回顾按当前同步范围内可信的批注修改时间统计主题和未处理问题；异常年份的历史记录单独列出，不推断阅读时长、完成情况或掌握程度。

## 部署到服务器

要求远端 Linux、Python 3、Docker 与 Compose，并且 SSH 用户可以使用 Docker。不会自动执行 sudo 或安装远端系统软件。

```sh
cd path/to/project
cp .env.example .env
# 填写自己的 DPT_DEPLOY_HOST、DPT_ADDRESS 或 APP_LISTEN_ADDRESS。
bash scripts/deploy.sh
```

新安装使用 `~/apps/dpt-syncer`，数据库为 `data/notes.sqlite3`。服务默认发布到用于访问 DPT 的局域网接口，部署脚本输出实际网页地址；不需要 SSH 隧道。

升级已有安装时，在私有 `.env` 中将 `DPT_REMOTE_ROOT` 设为原安装目录（相对 SSH 用户主目录），将 `DPT_DEPLOY_PROJECT` 设为原 Compose 项目名。这样继续使用原数据卷、配对凭据和访问口令，旧数据库文件也会自动识别；不能为同一安装随意更换目录或项目名。

首次部署会打印网页访问口令。浏览器登录状态最长保留 30 天，未登录无法访问笔记、PDF、设置或同步接口。升级保留口令。重置可在服务器执行：

```sh
cd ~/apps/dpt-syncer/current
python3 -m app.web_auth --file ~/apps/dpt-syncer/data/web-access.json --reset
docker compose restart
```

代码包与初始化数据分开打包；默认初始化包仅包含空数据库。使用 --include-pairing 才会复制配对凭据，此时初始化包属于私有文件，不能作为公开发行附件。归档中的用户名与组名会清空，文件属主统一归零，不写入打包电脑的用户身份。上传前校验 SHA-256，源文件权限规范化，镜像构建时以普通用户验证导入与静态文件读取。现有数据目录不会被初始化数据覆盖；升级前备份数据库，新容器未通过健康检查时尝试回滚。

部署需要能通过 SSH 连接自己的服务器。脚本会读取被 Git 忽略的 .env，使用 DPT_DEPLOY_HOST 或命令参数作为目标。首次部署需要 DPT_ADDRESS 或 APP_LISTEN_ADDRESS；升级优先保留服务器已有的网络配置。环境配置按普通文本解析，不执行命令、不展开变量；进程环境优先于 .env。部署成功后会保存网页地址，scripts/open.command 可以直接打开它。

## 数据与备份

持久数据包括数据库、PDF 版本、截图、原始本地副本、设备配对凭据、私有模型设置和网页登录配置。网页支持 JSON、Markdown 和数据库备份；完整恢复还需要整个数据目录中的 PDF、截图与凭据。

升级只添加目录元数据及设备在场标记等兼容字段，不删除历史记录。文档移出所选目录或从设备删除后，已有归档保留，后续不再自动处理它。同步过程中缩小范围时，不会继续归档或保存范围外的解读结果；已经发出的网络请求无法撤回。

复制运行中的数据库应使用 SQLite 备份接口，或者先停止服务，避免遗漏 WAL。长期保留多个 PDF 版本会占用存储空间，当前不自动清理。

## 本机运行与验证

```sh
.venv/bin/python -m pip install -r app/requirements.txt
.venv/bin/python -m app.server
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
node tests/test_frontend.cjs
node --check app/static/app.js
bash -n scripts/deploy.sh scripts/install_remote.sh
```

默认设备地址为空，需在网页或私有配置中填写。默认数据为 `output/data`，配对凭据为 `.tools/dpt-auth`；可以用 `--data`、`--auth`、`--port` 调整。检测到旧版本地数据时继续使用旧目录；也可以通过私有 `.env` 中的 `APP_DATA_DIR` 显式指定。模型服务地址从服务器/容器的网络位置解释，容器内的 localhost 指容器本身。

测试覆盖目录递归与边界、新文档自动纳入、范围外拒绝拉取和解读、迁移保留数据、范围变更时丢弃过期结果，以及原有 PDF、鉴权和解读流程。模型测试使用模拟响应；真实设备和模型连接需在运行环境验证。界面渲染检查不能替代实际浏览器排版验收。
